# gb-diversity-day

![gb-diversity-day](../../images/diversity-day.webp)

Triage step of the /gangbang workflow — scan the code a request touches, decide whether it's a feature, bug, refactor or small change, and propose the route and acceptance criteria. Use when /gangbang starts on a new request, or when the user types /gb-diversity-day.

The skill itself is in [SKILL.md](SKILL.md).
