# gb-how-dare-you

![gb-how-dare-you](../../images/howdareyou.jpg)

Review step of the /gangbang workflow — run /code-review on the changes plus a check against the project's conventions, and decide whether the build loop is clean or goes back to implement. Use when /gangbang reaches its review step, or when the user types /gb-how-dare-you.

The skill itself is in [SKILL.md](SKILL.md).
