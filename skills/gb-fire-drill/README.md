# gb-fire-drill

![gb-fire-drill](../../images/firedrill.gif)

Simulated manual testing step of the /gangbang workflow — with the user's permission, launch the app and check the criteria only a person could check (how a screen looks and behaves), capturing screenshots as proof. Use when /gangbang has manual criteria left before acceptance, or when the user types /gb-fire-drill.

The skill itself is in [SKILL.md](SKILL.md).
